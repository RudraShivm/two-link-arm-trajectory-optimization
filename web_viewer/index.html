Why Collocation Dramatically Outperforms Single Shooting on Continuous Replay

Single shooting treats control inputs as open-loop discrete piecewise-constant commands. Small integration deviations compound exponentially over time (Δx ∝ eλt). Direct collocation methods enforce dynamic continuity at every mesh node via defect equality constraints, producing robust trajectories with zero compounding drift.

Mathematical & Theoretical Foundations

Trajectory Optimization Formulations & Defect Equations

Rigorous mathematical formulation of the two-link planar robotic arm and direct transcription methods based on Cardona-Ortiz & Arechavaleta (2025) and Matthew Kelly (SIAM Review 2017).

Dynamics Two-Link Planar Manipulator Dynamics (Euler-Lagrange)
Generalized coordinates $\mathbf{q} = [\theta_1, \theta_2]^T \in \mathbb{R}^2$, state vector $\mathbf{x} = [\mathbf{q}^T, \dot{\mathbf{q}}^T]^T \in \mathbb{R}^4$, and actuator control torque $\boldsymbol{\tau} = [\tau_1, \tau_2]^T \in \mathbb{R}^2$.
$$M(\mathbf{q})\ddot{\mathbf{q}} + C(\mathbf{q}, \dot{\mathbf{q}})\dot{\mathbf{q}} + \mathbf{g}(\mathbf{q}) = \boldsymbol{\tau}$$ $$M(\mathbf{q}) = \begin{bmatrix} I_1 + I_2 + m_1 r_1^2 + m_2 (l_1^2 + r_2^2 + 2 l_1 r_2 \cos\theta_2) & I_2 + m_2 (r_2^2 + l_1 r_2 \cos\theta_2) \\ I_2 + m_2 (r_2^2 + l_1 r_2 \cos\theta_2) & I_2 + m_2 r_2^2 \end{bmatrix}$$ $$C(\mathbf{q}, \dot{\mathbf{q}})\dot{\mathbf{q}} = \begin{bmatrix} -m_2 l_1 r_2 \sin\theta_2 (2\dot{\theta}_1 \dot{\theta}_2 + \dot{\theta}_2^2) \\ m_2 l_1 r_2 \sin\theta_2 \dot{\theta}_1^2 \end{bmatrix}, \quad \mathbf{g}(\mathbf{q}) = \begin{bmatrix} (m_1 r_1 + m_2 l_1) g \cos\theta_1 + m_2 r_2 g \cos(\theta_1 + \theta_2) \\ m_2 r_2 g \cos(\theta_1 + \theta_2) \end{bmatrix}$$
End-Effector Forward Kinematics $\mathbf{p}_{ee} = [l_1 \cos\theta_1 + l_2 \cos(\theta_1+\theta_2), \; l_1 \sin\theta_1 + l_2 \sin(\theta_1+\theta_2)]^T$
Continuous Optimal Control Objective $\min_{\boldsymbol{\tau}} J = \int_0^T \|\boldsymbol{\tau}(t)\|_2^2 \, dt \quad \text{s.t.} \quad |\tau_i(t)| \le \tau_{\max}$
Method 1 Single Direct Shooting (Runge-Kutta 4th Order)
Decision variables are exclusively parameterized controls $\mathbf{z} = [\boldsymbol{\tau}_0, \boldsymbol{\tau}_1, \dots, \boldsymbol{\tau}_{N-1}]^T \in \mathbb{R}^{2N}$. States are generated sequentially forward in time via explicit RK4 simulation:
$$\mathbf{x}_{k+1} = \mathbf{x}_k + \frac{h}{6}(\mathbf{k}_1 + 2\mathbf{k}_2 + 2\mathbf{k}_3 + \mathbf{k}_4)$$ $$\mathbf{k}_1 = \mathbf{f}(\mathbf{x}_k, \boldsymbol{\tau}_k), \quad \mathbf{k}_2 = \mathbf{f}\left(\mathbf{x}_k + \frac{h}{2}\mathbf{k}_1, \boldsymbol{\tau}_k\right), \quad \mathbf{k}_3 = \mathbf{f}\left(\mathbf{x}_k + \frac{h}{2}\mathbf{k}_2, \boldsymbol{\tau}_k\right), \quad \mathbf{k}_4 = \mathbf{f}(\mathbf{x}_k + h\mathbf{k}_3, \boldsymbol{\tau}_k)$$ $$\text{Boundary Equality Constraint: } \mathbf{x}_N - \mathbf{x}_{\text{target}} = \mathbf{0} \in \mathbb{R}^4$$
Decision Variable Count $\dim(\mathbf{z}) = 2N$ (Controls only)
Jacobian Structure Dense, ill-conditioned ($\kappa \propto e^{\lambda T}$)
Obstacle Handling High penalty sensitivity at discrete sample points
Method 2 Trapezoidal Direct Collocation ($O(h^2)$ 2nd-Order Collocation)
Both states and controls are simultaneous decision variables at every mesh node: $\mathbf{z} = [\mathbf{x}_0, \boldsymbol{\tau}_0, \mathbf{x}_1, \boldsymbol{\tau}_1, \dots, \mathbf{x}_N, \boldsymbol{\tau}_N]^T \in \mathbb{R}^{6(N+1)}$. Dynamics are converted into implicit algebraic defect equality constraints:
$$\boldsymbol{\zeta}_k = \mathbf{x}_{k+1} - \mathbf{x}_k - \frac{h_k}{2}\left[\mathbf{f}(\mathbf{x}_k, \boldsymbol{\tau}_k) + \mathbf{f}(\mathbf{x}_{k+1}, \boldsymbol{\tau}_{k+1})\right] = \mathbf{0}, \quad k = 0, \dots, N-1$$ $$\text{Objective Quadrature: } J = \sum_{k=0}^{N-1} \frac{h_k}{2}\left(\|\boldsymbol{\tau}_k\|_2^2 + \|\boldsymbol{\tau}_{k+1}\|_2^2\right)$$ $$\text{Path Constraint: } \|\mathbf{p}_{ee}(\mathbf{q}_k) - \mathbf{p}_{\text{obs}}\|_2 \ge r_{\text{obs}} + r_{\text{margin}}, \quad \forall k$$
Decision Variable Count $\dim(\mathbf{z}) = 6(N+1)$ (States + Controls)
Defect Constraints $4N$ equality constraints
Jacobian Structure Block-banded sparse, highly scalable
Method 3 Hermite-Simpson Direct Collocation ($O(h^4)$ Separated Form)
Higher-order direct collocation evaluating states and controls at mesh nodes $t_k$ and interval midpoints $t_{k+1/2}$. Employs cubic Hermite state interpolation and Simpson quadrature:
$$\text{Hermite Midpoint: } \mathbf{x}_{k+1/2} = \frac{1}{2}(\mathbf{x}_k + \mathbf{x}_{k+1}) + \frac{h_k}{8}\left[\mathbf{f}_k - \mathbf{f}_{k+1}\right]$$ $$\text{Simpson Defect: } \boldsymbol{\zeta}_k = \mathbf{x}_{k+1} - \mathbf{x}_k - \frac{h_k}{6}\left[\mathbf{f}_k + 4\mathbf{f}_{k+1/2} + \mathbf{f}_{k+1}\right] = \mathbf{0}$$ $$\text{Objective Quadrature: } J = \sum_{k=0}^{N-1} \frac{h_k}{6}\left(\|\boldsymbol{\tau}_k\|_2^2 + 4\|\boldsymbol{\tau}_{k+1/2}\|_2^2 + \|\boldsymbol{\tau}_{k+1}\|_2^2\right)$$
Truncation Error $O(h^4)$ 4th-Order Accuracy
Midpoint Evaluation Evaluated at mesh midpoints $t_k + h_k/2$
Continuous Tracking Fidelity Lowest drift on continuous 8th-order DOP853 replay
